# meridian-prompter

The prompt-engineering package provides agents and skills for writing, reviewing, and testing instructions agents read. Its [prompt principles](prompt-principles.md) distinguish craft from Meridian-specific artifact formats, which version with the CLI. Checks scale with the uncertainty and consequences of a change; behavioral experiments require a defined question and scope.

The package is a local dependency rather than a foundation for other prompt packages; see the [package overview](overview.md#prompter-is-local-not-a-foundation).
