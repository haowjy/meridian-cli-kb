# Prompt Principles

The `/prompt-principles` skill in [meridian-prompter](meridian-prompter.md) owns prompt craft. Meridian-specific artifact formats live in the bundled authoring guidance, so harness changes need not change the general doctrine.

Do not treat fixed agent-function counts, fixed iteration limits, fixed skill lengths, or an estimated percentage of context lost per handoff as established evidence. Persona effects vary by task; a separate model family is not a prerequisite for independent review.
