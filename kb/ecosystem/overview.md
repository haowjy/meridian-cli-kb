# Ecosystem Overview

Meridian coordinates agents; [Mars](../concepts/package-management/overview.md) resolves prompt packages and projects them into harness-native formats. [Prompt packages](prompt-packages/overview.md) provide shared and domain-specific instructions. [Domain packages](domain-packages.md) apply the ecosystem to particular workflows, including [Jupyter Workbench](jupyter-workbench/overview.md) and [microCT analysis](microct-analysis/overview.md).
