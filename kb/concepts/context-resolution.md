# Context Resolution

Context identifies working-memory paths for agents; [workspace projection](workspace-projection.md) grants filesystem access. These serve different purposes even when they name the same directory.

In a managed run, the active work path is a per-chat link that follows work changes; see [session work links](../decisions/session-work-links.md). Context configuration and path resolution are documented in `docs/configuration/context.md` in meridian-cli.
