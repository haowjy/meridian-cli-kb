# Spawn Lane Operations

Configured backup models are prelaunch candidates; an authentication or capacity failure after launch does not trigger fallback. Resume the work with an explicit alternative route and report credential failures.

## A Claude Lane's Background Gate Was Killed, and Reported Succeeded

A prompting workaround for a harness defect is a deferral, not a fix. Check whether the product's own guidance contradicts the workaround. See [completion drain](../decisions/completion-drain.md#d-claude-native-hold).

On a shared host, select processes to stop by a handle recorded when starting them, not command-line text: agent prompts can appear in another process's arguments. Git worktrees also share the repository's stash list; use a temporary commit on an owned branch to set work aside.

## Parallel Lanes Can Collide on Test Basenames

With pytest's default import mode, identically named test files in non-package directories can pass separately and fail collection when combined. Agree on package directories or unique basenames, then test the integrated tree.
